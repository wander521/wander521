# Wang Bo · 汪博

**AI Agent / Embodied Intelligence Developer**

I develop **AI agents and embodied intelligence agents** at the **Wuhan Artificial Intelligence Research Institute** (October 2024–present). My work connects natural language, perception, task orchestration and robot execution to bring agent capabilities into real-world applications.

I led the design and development of **RoboClaw, an embodied AI data collection system, and an embodied AI training platform**. My work spans robot interaction and control, navigation and inspection, data collection and management, and hands-on learning with real robots.

[Portfolio](https://wander521.github.io/robot-portfolio/) · [Get in touch](https://wander521.github.io/robot-portfolio/#contact)

## Projects I led

### RoboClaw

**Embodied interaction and robot task execution platform**

Built on Nanobot, RoboClaw connects language interaction, task planning, skills and tool calls, a robot gateway, and hardware adapters into an execution pipeline.

- Integrated real-time voice, visual detection, remote control and takeover, robot actions and dexterous hand control; adapted the platform for Unitree G1 and Leju Kuavo 4PRO MaxA.
- Integrated robot-side SLAM and localization services; developed map, waypoint and route management; orchestrated navigation, narration and gestures for exhibition tours and inspection tasks.
- Developed a point-cloud dashboard showing LiDAR scans, robot position, heading and travel paths, alongside a separate inspection platform and device-side execution service.
- Developed **HiRobo**, the companion Android app for device management, conversations, remote control, skills and tasks; integrated dual-arm grasp-and-place workflows and VLA services.

[Explore the project & demos →](https://wander521.github.io/robot-portfolio/projects/roboclaw/)

### Embodied AI Data Collection

**embodied-ai-data-collect · From robot operations to managed data assets**

Organizes collection around tasks, episodes and datasets, connecting task assignment, robot leases, collection control, upload and conversion, dataset management and annotation.

- Connected device runtimes, collection state and event reporting to make tasks and collection runs traceable.
- Developed workflows for episode uploads, LeRobot conversion, dataset management and annotation.
- Integrated synchronized replay of multiple cameras, actions and states for data review and troubleshooting.

[Explore the project & demos →](https://wander521.github.io/robot-portfolio/projects/embodied-ai-data-collect/)

### Embodied AI Training Platform

**From course organization to code experiments on real robots**

Connects course content, classroom teaching, learning progress and robot experiment entry points so that teachers can organize courses and students can practice in authorized environments.

- Developed course-package import and publishing, class and enrollment management, chapter learning and experiment submission.
- Integrated protected Notebook environments and robot bindings, connecting code experiments, ROS 2 and robot actions.
- Designed teacher and student workflows that link course learning with device practice.

[Explore the project & demos →](https://wander521.github.io/robot-portfolio/projects/embodied-ai-training/)
