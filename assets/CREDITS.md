# 素材说明

个人主页的近景横幅使用网站所有者提供的机器人网页录屏，裁去浏览器、录屏控件与鼠标指针，重新编排为固定标题、贴底流程条和往返循环动画。原始录屏不上传；只发布生成的横幅和静态替代图。画面中的机器人网格来自 Unitree Robotics 官方 `unitree_ros` 仓库中的 G1+ `g1_pl` URDF / STL。

- 来源：https://github.com/unitreerobotics/unitree_ros/tree/master/robots/g1_description
- 许可证：[BSD-3-Clause](UNITREE-LICENSE.txt)
- 修改：网格转换、银白金属材质、灯光、镜头与网页动画。
- 横幅是个人主页视觉动画；项目记录和视频可从各项目链接查看。
- 横幅中文字体：Noto Serif SC，SIL Open Font License。

横幅为本地生成并随仓库保存的图片，不依赖第三方统计卡片或图片生成服务。

平台与技术徽章使用 [Simple Icons](https://github.com/simple-icons/simple-icons) 的 SVG 几何，按仓库内 [CC0 许可](SIMPLE-ICONS-LICENSE.md) 使用；品牌名称与标识属于各自权利人。标为 Coming soon / Soon 的平台尚未绑定账号地址，不表示已有社群。

GitHub Activity 动画由本仓库 `tools/activity.py` 根据 GitHub 的公开贡献日历生成，颜色等级来自原始日历，没有补造贡献记录。`tools/badges.py` 生成本地徽章；Agent 链路图为本仓库原生 SVG。
